# Filter List Licenses & Provenance Policy

> **Milestone:** M0 (Research & Compliance)  
> **Last updated:** 2026-08-12

This document details the licensing status, attribution requirements, and distribution policies for all filter lists, rulesets, and snippets evaluated or utilized within ADAPT Phase 1.

---

## 1. Legal Distinction: Code vs. Data

In accordance with Rule R4, ADAPT strictly distinguishes between:
1. **Source Code License**: The license governing the extension's execution logic (TypeScript, build scripts, tests).
2. **Filter Data License**: The license governing the structured rules, URLs, regexes, and cosmetic selectors bundled with or generated by the extension.

## 3. ADAPT Phase 1 Filter Strategy

### 3.1 Initial Architecture Baseline (Stage A)
- For development and the synthetic test laboratory (T01–T25), ADAPT uses an **internally authored, clean-room test ruleset** (`src/rules/static/baseline.json`).
- This eliminates all external licensing coupling during the core engine validation and transaction test suite.

### 3.2 Production List Integration (Stage B & C)
- When integrating global baseline subscriptions in Milestone M7, ADAPT will generate declarative DNR JSON from standard public lists under **CC BY-SA 3.0**, maintaining clear separation from the application code layer.
- Provenance metadata (source URL, version/hash, build timestamp, license notice) will be embedded in `src/rules/static/provenance.json`.
